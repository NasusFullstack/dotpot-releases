# 도트 화분 (Dot Pot)

모니터 오른쪽 아래, 작업 표시줄 위에 떠 있는 작은 도트 화분이에요.
게임을 켜 두는 동안 조금씩 자라는 꽃과 나무를 키워 보세요.

만든이: **radiant9312** (radiant9312@gmail.com)

이 저장소는 배포 파일만 두는 곳이에요. 받기는 오른쪽 **Releases** 에서 최신 `DotPot_vX.Y.Z.zip` 을 받으세요.

## 시작하기
1. `DotPot_vX.Y.Z.zip` 을 받아 바탕화면·문서 폴더 등 **쓰기 가능한 폴더**에 풉니다.
2. `DotPot/DotPot.exe` 를 실행합니다. (같은 폴더의 `DotPot.pck` 가 필요해요)
3. 빈 화분을 누르면 「무엇을 키워볼까요?!」 꾸러미가 열려요.

- 꽃 8종 · 잎 8종 · 화분 8종 · 여러 색이 랜덤으로, 나무 5종(은행·단풍·벚·소나무·고무나무)
- 물주기 · 영양제로 돌봐 주세요. 너무 적어도, 너무 많아도(과습·비료 과다) 아파요.
- 게임을 켜 둔 시간만큼 자라요 (꽃 약 24시간, 나무 약 56시간). 꺼 두면 멈춰요.
- 잘 돌본 나무에게는 숨은 단계가, 무지갯빛 꾸러미에서는 파스텔 색 식물이 나와요.
- 작업 표시줄에는 안 뜨고, 시계 옆 트레이의 꽃 아이콘에서 보이기·숨기기·크기·보관함 등을 고를 수 있어요.

## 저장과 개인 정보
- 저장은 이 PC 에만 (`%APPDATA%\Godot\app_userdata\도트 화분\garden.dat`), 윈도우 계정으로만 열 수 있게 암호화돼요.
- 다른 PC 로 옮길 때는 트레이 메뉴 「저장 → 내보내기」로 비밀번호를 정한 백업 파일을 만들어 「가져오기」 하세요.
- 인터넷 연결은 자동 업데이트 확인(이 저장소의 최신 릴리스 확인)과 파일 내려받기뿐이에요. 저장 내용은 보내지 않아요.

## 자동 업데이트
켤 때와 6시간마다 이 저장소의 최신 릴리스를 확인해요. 새 판은 **만든이의 서명**(`DotPot.manifest.sig`)과
크기·SHA-256 이 맞을 때만 받아 두었다가, 게임을 끌 때 바꿔 끼워요(이전 판은 `DotPot.pck.bak` 으로 남김).
트레이 메뉴 「업데이트 → 자동 업데이트」로 끌 수 있어요.

릴리스 파일
| 파일 | 설명 |
|---|---|
| `DotPot_vX.Y.Z.zip` | 처음 받는 사람용 전체 (실행기 + 게임 묶음 + 읽어보세요) |
| `DotPot.pck` | 자동 업데이트용 게임 묶음 (zip 안의 것과 같은 파일) |
| `DotPot.manifest.json` / `.sig` | 판·크기·SHA-256 과 그 서명 |
